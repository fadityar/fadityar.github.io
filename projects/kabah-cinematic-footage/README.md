# Ka'bah Cinematic Footage

Website statis siap deploy ke Vercel untuk menampilkan photos, videos, dan content mengenai Makkah.

## Jalankan lokal

Buka `index.html` langsung di browser, atau gunakan extension Live Server di Visual Studio Code.

## Deploy ke Vercel

Import folder ini ke Vercel. Karena ini website statis, tidak perlu build command.
